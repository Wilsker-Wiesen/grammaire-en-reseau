# Übersetzungsleitfaden: Grammaire en réseau (Französisch → Deutsch)

Zielgruppe: deutschsprachige Lernende (Schule/Uni), die französische Grammatik lernen. Die Erklärungen werden deutsch, alle französischen Sprachbeispiele bleiben französisch.

## Was übersetzt wird – was nicht

**Übersetzen:** die erklärende Prosa (Regeln, Definitionen, Hinweise, Überschriften, Tabellenköpfe mit Erklärtext, Zwischentitel), auch wenn sie kursiv steht.

**Unverändert französisch lassen (Zeichen für Zeichen):**
- Beispielsätze und Beispielwörter (meist kursiv `<em>…</em>`, in Anführungszeichen, nach „Ex. :“, in Tabellenzellen mit Beispielen).
- Französische Wörter/Formen, über die gesprochen wird: *quoique*, *leur*, *-ent*, *ce/se*, Endungen, Konjugationsformen, Listen von Verben/Nomen, Homophonpaare.
- Eigennamen, Werktitel, Zitate.
- Titel, die nur aus den behandelten französischen Wörtern bestehen (z. B. „Ces, ses“, „Quoique, quoi que“, „Tout“, „Leur, leurs“, „Bouillir“).
Im Zweifel: Ist es ein Beispiel der Sprache oder eine Erklärung über die Sprache? Beispiel → Französisch lassen. Erklärung → Deutsch.

## HTML – streng
- Die HTML-Struktur bleibt exakt gleich: dieselben Tags in derselben Reihenfolge, dieselben Attribute (`href`, `class`, `id`, `colspan` …). Nur Textinhalte ändern.
- Keine Tags hinzufügen, entfernen, zusammenlegen oder umsortieren. Wenn ein deutscher Satz eine andere Wortstellung braucht, verteile den Text sinnvoll auf die vorhandenen Tags.
- Linktexte (`<a href="#/regle/…">Text</a>`) übersetzen, `href` nie ändern.
- Entitäten/Sonderzeichen wie im Original beibehalten.

## Stil
- Klar, sachlich, gut lesbares Deutsch für Lernende. Lernende direkt mit „du“ ansprechen, wo der Text sie anspricht („Notez que…“ → „Beachte, dass …“).
- Inhalt vollständig und genau übertragen: nichts weglassen, nichts hinzufügen, keine eigenen Erklärungen ergänzen.
- Französische Anführungszeichen « » in deutschen Sätzen → „ “; innerhalb französischer Beispiele « » belassen.
- Abkürzungen: „ex.“ → „z. B.“ / „Bsp.“, „cf.“ → „vgl.“, „p. ex.“ → „z. B.“.

## Titel
Fiche-Titel ins Deutsche übersetzen (kurz, wie ein Kapitelname), außer sie bestehen nur aus behandelten französischen Wörtern. Beispiele: „L'accord de l'adjectif“ → „Angleichung des Adjektivs“; „La proposition subordonnée“ → „Der Nebensatz“; „Le subjonctif“ → „Der subjonctif“; „Ces, ses“ → „Ces, ses“; „Passé simple, verbes réguliers du 1er groupe“ → „Passé simple: regelmäßige Verben der 1. Gruppe“.

## Übungsanweisungen (strings_*.json)
Anweisungen als Aufforderung in der du-Form: „Complétez les phrases suivantes avec …“ → „Ergänze die folgenden Sätze mit …“; „Mettez au pluriel“ → „Setze in den Plural“. Französische Wörter/Beispiele in der Anweisung bleiben französisch („la ou le“, „tout“, „à ou a“). Nummern/Präfixe wie „31.-“, „I.12“, „GrammII.3“ unverändert lassen. Enthält ein String nur französische Beispielsätze oder Namen (z. B. ein Liedtitel, „Texte à trous : Athènes“ → „Lückentext: Athènes“), nur den erklärenden Teil übersetzen. HTML in Strings unverändert lassen.
